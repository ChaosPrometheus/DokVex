# DokVex

Локальный веб-инструмент для сжатия документов на Python.

## Возможности

* 📄 Сжатие PDF
* 📝 Сжатие DOCX
* 📊 Сжатие XLSX
* 📽️ Сжатие PPTX
* 📉 Оптимизация изображений внутри Office-документов
* 📊 Сравнение размера файла до и после обработки
* 📥 Автоматическое скачивание результата
* 🌙 Светлая и тёмная тема
* 🌐 Работа в локальной сети
* 🔒 Обработка файлов локально

## Технологии

* Python 3.10+
* Flask
* PyMuPDF
* Pillow
* ZIP / Open XML
* HTML / CSS / JavaScript

Office-документы обрабатываются напрямую через Open XML без использования LibreOffice и других офисных программ.

## Поддерживаемые форматы

| Формат | Возможность |
| ------ | ----------- |
| PDF    | Сжатие      |
| DOCX   | Сжатие      |
| XLSX   | Сжатие      |
| PPTX   | Сжатие      |

Максимальный размер загружаемого файла — **50 МБ**.

## Установка

```bash
git clone https://github.com/ChaosPrometheus/DokVex.git
cd DokVex
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

После запуска сайт доступен на:

```text
http://127.0.0.1:5000
```

Для доступа с других компьютеров в локальной сети:

```text
http://IP-АДРЕС-СЕРВЕРА:5000
```

## Доступ по адресу dokvex.local

DokVex можно открывать в браузере по удобному адресу:

```text
http://dokvex.local
```

Для этого на каждом компьютере, с которого необходимо открыть DokVex, нужно добавить запись в файл `hosts`.

### 1. Откройте Блокнот от имени администратора

Нажмите:

```text
Пуск → Блокнот → Запуск от имени администратора
```

### 2. Откройте файл hosts

В Блокноте откройте:

```text
C:\Windows\System32\drivers\etc\hosts
```

Если файл не отображается, выберите тип:

```text
Все файлы (*.*)
```

### 3. Добавьте адрес сервера

В конец файла добавьте:

```text
192.168.2.222    dokvex.local
```

`192.168.2.222` необходимо заменить на IP-адрес компьютера, на котором запущен DokVex.

### 4. Сохраните файл

После сохранения откройте браузер и перейдите:

```text
http://dokvex.local
```

Если DokVex запущен на другом компьютере в локальной сети, этот компьютер должен быть доступен по сети.
